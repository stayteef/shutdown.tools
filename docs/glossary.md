# Glossary

Plain-language explanations of the technical terms used across this site.

## IP address { #ip }
An IP (Internet Protocol) address is a unique numerical identifier assigned to every device connected to a computer network, like a home address for your device.

## LoRa { #lora }
LoRa is short for "Long Range". It is a type of radio signal that sends small amounts of data over long distances using very little power.

## APK { #apk }

An APK is the file for an Android app, like a `.exe` on Windows. It lets you install the app directly on your phone, without going through an app store, which is useful when the store is blocked or the app isn't listed.
